Built-in strategy research

Deterministic simulated time. Configure and run in the browser.

  1. 1Choose trading task and strategy

    Execution: TWAP or immediate sweep.
    Market making: fixed spread or inventory aware.

  2. 2Configure the experiment

    Strategy orders, timing and risk; instrument, liquidity, fees and latency; matched seeds and run bounds.

  3. 3Review assumptions, then run

    Validate first. Launch the seed runs; pause or step when inspecting behavior.

  4. 4Compare and explain

    Create a variant. Compare eligible paired seeds, then inspect individual fills and decisions.

The strategy talks directly to the matching engine. No exchange protocol is selected for this mode.
